# Página Pessoal - Linguagens de Marcação

Este projeto consiste na criação de uma página web pessoal desenvolvida como atividade prática para a Unidade Curricular de **Linguagens de Marcação**. O objetivo principal é aplicar elementos semânticos do HTML5, garantindo acessibilidade, clareza na estrutura e boas práticas de desenvolvimento web.

---

##  Sobre o Projeto

A página apresenta uma breve introdução sobre mim, meus principais hobbies e interesses cotidianos, além das minhas aspirações profissionais voltadas para a área da saúde e comportamento humano.

### Objetivos Concluídos:
- [x] Estruturação do documento em HTML5.
- [x] Uso de tags semânticas para melhor acessibilidade e SEO.
- [x] Integração de fontes externas via **Google Fonts**.
- [x] Criação de um layout limpo e organizado.
- [x] Comentário reflexivo sobre a escolha das tags e boas práticas.

---

##  Tecnologias Utilizadas

- **HTML5**: Estruturação semântica do conteúdo.
- **CSS3**: Estilização básica e aplicação de fontes.
- **Google Fonts**: Importação da tipografia para melhoria visual.

---

##  Estrutura das Tags e Semântica

A página foi construída priorizando a **semântica** e a **acessibilidade**:

* `<header>`: Agrupa o cabeçalho principal com o nome e a apresentação inicial.
* `<main>`: Delimita todo o conteúdo principal da página.
* `<section>`: Divide o conteúdo em blocos temáticos ("Sobre Mim", "Hobbies" e "Futuro Profissional").
* `<h1>` - `<h2>`: Organização hierárquica dos títulos para facilitar a leitura e navegação por leitores de tela.
* `<ul>` e `<li>`: Listagem organizada dos hobbies e interesses.
* `<footer>`: Rodapé contendo as informações de direitos autorais e copyright.

---

eflexão sobre Boas Práticas e Acessibilidade

O uso correto de elementos semânticos (`<header>`, `<main>`, `<section>`, `<footer>`) no lugar de divisões genéricas (`<div>`) permite que leitores de tela e motores de busca compreendam a estrutura lógica do documento. Além disso, a definição do atributo `lang="pt-br"` na tag `<html>` garante que softwares de síntese de voz leiam o conteúdo com a pronúncia correta.
